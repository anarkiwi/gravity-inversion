# gravity-inversion

C64 SID playroutines translated from 6502 machine code to C with the
[llvm-mos SDK](https://github.com/anarkiwi/docker-mos-llvm-sdk). Each translation issues
the same SID register writes, in the same order and play call, as the original up to the
tune's end.

Tunes and their data are not part of this repository: each tune's build fetches its
original (MD5-pinned) into `fixtures/`, which CI caches, and generates the C data header
from it byte-identical.

## Use

    docker build .            # lint, build, compare, test

or, with `mos-c64-clang`, `acme` and `requirements-dev.txt` installed:

    make                      # tunes/*/build/*.prg
    make check                # compare each tune's SID writes against its original
    make test lint

Each tune Makefile sets `GEN := 1` (with `PSID` and `CHECK_ARGS`) before including
`common.mk`, so `make` also builds `build/gen.prg` from `build/gen/<tune>.c` and `.h`,
generated by `tools/transliterate.py`, and `make check` compares it with sidtrace too.

## Layout

| Path | Content |
|---|---|
| `tunes/<name>/` | one translation: C player, data generator, tests, notes |
| `c64/driver.c` | shared C64 driver: `tune_init`, then `frame_wait` / `tune_play` per call |
| `common.mk` | shared make rules: fixtures, the C build; `GEN := 1` adds the generated translation |
| `tools/sidtrace.py` | SID write tracer and comparator per subtune, on pysidtracker's C64 (vagrant-moses machine, jennings CPU, power-on RAM) |
| `tools/disasm.py` | jennings coverage-driven disassembly listing of a PSID |
| `tools/survey.py` | rank tunes by the playroutine code they execute; branch outcome gaps |
| `tools/constructs.py` | validate `tunes/*/constructs.json`, each 6502 construct's hand-C form ([docs/constructs.md](docs/constructs.md)), against jennings coverage |
| `tools/opclass.py` | every opcode's roles in the lift procedure, from deity-informant's P-code |
| `tools/passes.py` | procedure graphs and loop kinds; the minimum number of lift passes ([docs/passes.md](docs/passes.md)) |
| `tools/sizes.py` | PRG size bounds relative to the original 6502 player ([docs/sizes.md](docs/sizes.md)) |
| `tools/eventlog.py` | note events and their register operations from generated C and a SID write log ([docs/eventlog.md](docs/eventlog.md)) |
| `tools/initiations.py` | song data reads of generated C and their reach to the frequency registers: value analysis of its LLVM IR (`tools/irmodule.py`; read tags `tools/irtags.py`; needs `clang`) |
| `tools/costs.py` | constructs in generated C that cost code size ([docs/costs.md](docs/costs.md)) |
| `tools/ablate.py` | where a generated translation's PRG bytes go: cumulative ablation of its C (AST model in `tools/cflow.py`) and a data accounting ([docs/ablate.md](docs/ablate.md)) |
| `tools/copies.py` | repeated playroutine code: unrolled copies with operand strides, JSR targets, fall-through entries |
| `tools/mutate.py` | mutation check: run a test command against source edits |
| `tools/transliterate.py` | PSID → `.c` + `.h` with vagrant-moses' `cgen` (needs `mlir-opt` 22, `clang-format`) |
| `tools/header.py` | shared CLI of the tune data generators |
